# بناء APK عبر GitHub

ينشئ ملف `.github/workflows/android-apk.yml` ملف APK داخل خادم GitHub عند كل دفع إلى الفرع `main` يمس ملفات التطبيق، أو عند تشغيل سير العمل يدويًا من تبويب **Actions**.

## تشغيل يدوي

افتح مستودع GitHub، ثم اختر **Actions**، وبعدها **Build Android APK**، واضغط **Run workflow**. اختر `debug` لتجربة سريعة قابلة للتثبيت، أو `release` لنسخة إصدار غير موقعة للنشر التجاري.

بعد نجاح التنفيذ، افتح صفحة التنفيذ وانزل إلى قسم **Artifacts**. حمّل ملف `AH4-Watch-Party-debug` أو `AH4-Watch-Party-release`، ثم فك الضغط عن الملف لتحصل على APK.

> نسخة `debug` موقعة بمفتاح تطوير ومناسبة للاختبار على جهاز Android. النشر على متجر Google Play يحتاج لاحقًا مفتاح توقيع إصدار محفوظًا في أسرار GitHub، وهي خطوة منفصلة لحماية مفتاحك الخاص.
