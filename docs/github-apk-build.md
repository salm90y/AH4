# بناء APK عبر GitHub

ينشئ ملف `.github/workflows/android-apk.yml` ملف APK مستقلًا داخل خادم GitHub عند كل دفع إلى الفرع `main` يمس ملفات التطبيق، أو عند تشغيل سير العمل يدويًا من تبويب **Actions**. تعتمد النسخة على بناء `Release` وتتحقق من وجود حزمة JavaScript داخل الـ APK قبل رفعه، لذلك لا تحتاج إلى خادم Metro أو Expo Go عند تشغيلها على الهاتف.

## تشغيل يدوي

افتح مستودع GitHub، ثم اختر **Actions**، وبعدها **Build Android APK**، واضغط **Run workflow**. اختر `standalone` لإنشاء APK مستقل قابل للتثبيت مباشرة على جهاز Android.

بعد نجاح التنفيذ، افتح صفحة التنفيذ وانزل إلى قسم **Artifacts**. حمّل ملف `AH4-Watch-Party-standalone`، ثم فك الضغط عن الملف لتحصل على APK.

> هذه نسخة مستقلة للاختبار وموقعة افتراضيًا بمفتاح بناء محلي. النشر على متجر Google Play يحتاج لاحقًا مفتاح توقيع إصدار محفوظًا في أسرار GitHub، وهي خطوة منفصلة لحماية مفتاحك الخاص.
