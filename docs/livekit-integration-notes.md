# LiveKit Integration Notes

## المسار التقني المعتمد

ستستخدم حزمة الاتصال الأصلية لـ LiveKit في إصدار Android متقدم. يتطلب ذلك تضمين حزم React Native وWebRTC، وإضافة مكونات Expo الخاصة بـ LiveKit وWebRTC، واستدعاء `registerGlobals()` قبل إنشاء أي غرفة. يتطلب هذا مسار بناء مستقلًا؛ إذ لا تعمل هذه الحزم داخل Expo Go.

## الصوت والكاميرا

يبدأ التطبيق جلسة الصوت عند دخول الغرفة فقط، ثم ينشر الميكروفون والكاميرا بموافقة المستخدم. سيُفصل وضع الاتصال المفتوح عن الهوكي توكي: الهوكي توكي ينشر الميكروفون عند الضغط فقط، بينما الاتصال يفعّله باستمرار، ولا يسمح التطبيق بتشغيل الوضعين معًا.

## الدردشة

ستُرسل رسائل الغرفة كحزم LiveKit موثوقة تحت موضوع مستقل. هذا مناسب للدردشة القصيرة داخل الغرفة، مع إظهار الرسائل المحلية فورًا واستقبالها من بقية المشاركين. لا تُستخدم الحزم لتخزين تاريخ دائم؛ وسيُضاف التخزين لاحقًا إذا تطلب المنتج سجلًا طويلًا.
